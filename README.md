Bonus Task — Dijkstra's Algorithm
Description

This project was extended with Dijkstra’s Algorithm to calculate the shortest path from a starting vertex to all other vertices in a weighted graph.

Implemented Features

- Added weighted edges
- Modified Edge class with weight field
- Updated graph structure to support weights
- Implemented `dijkstra(int start)` method
- Calculated shortest distances from a selected vertex

Technologies

- Java
- Adjacency List

Example Output

Shortest distances from vertex 0:

To vertex 0 = 0
To vertex 1 = 3
To vertex 2 = 1
To vertex 3 = 4
To vertex 4 = 7

Repository Structure

- `Edge.java` — edge representation with weights
- `Graph.java` — graph implementation and Dijkstra algorithm
- `Main.java` — example execution



How to Run

1. Open the project in IntelliJ IDEA
2. Run Main.java
3. The shortest distances will be displayed in the console
